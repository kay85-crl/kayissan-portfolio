# Service Booking Web Application

This project was developed as a personal project during my web development studies.

The goal of the project was to build a responsive, user-friendly and accessible web application
with a clear booking flow and interactive functionality using modern web standards.

## Features

- Multi-page website structure
- Responsive design for desktop, tablet and mobile
- Booking flow with calendar-based date selection
- Client-side form validation
- Clear user feedback and interaction
- Modular JavaScript structure
- SEO-friendly and semantic HTML

## Technologies Used

- HTML5 (semantic markup)
- CSS3
- JavaScript (ES6+)
- Bootstrap
- Git

## Focus Areas

- Accessibility (a11y)
- User experience (UX)
- Responsive user interfaces
- Clean and readable code
- Separation of concerns
